### About me

- 🔨 I build in public — every project here is **free forever** and open source
- 🧰 Creator of **[pocket-tools](https://github.com/rudransh175/pocket-tools)** — useful tools that each live in a *single HTML file*, work offline, and need no install
- 📱 Creator of **[Veto](https://github.com/rudransh175/veto)** — a free Android blocker for Reels & Shorts with focus timer and per-app limits
- 🎬 I also run **[WhatIfVerse](https://www.youtube.com/@askwhatifverse)** — 5-second "what if" disaster Shorts on YouTube & Instagram
- 🌱 Currently exploring **Rust, Android (Kotlin), and game dev** — including an independent Rust-powered voxel game
- 💬 I like honest tools, clean design, and shipping things people can actually use
